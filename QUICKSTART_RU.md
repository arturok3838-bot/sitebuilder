# Быстрый запуск ARTurokAI на компьютере (тест: сайт + админ + подписки)

Для этого теста видеокарта и ключи НЕ нужны. Работают: регистрация, вход,
личный кабинет, админ-панель, генерация кодов-подписок, таблицы.
(ИИ-генерация фото/видео/кода требует отдельной настройки — см. README.)

## 1. Установить Python
- Windows: https://www.python.org/downloads/ — при установке поставьте галочку
  **«Add Python to PATH»**.
- macOS: https://www.python.org/downloads/ (или `brew install python`).

## 2. Скачать проект
На странице репозитория на GitHub:
1. Вверху переключите ветку на **ccr-6156c21e-10j8dk**.
2. Кнопка **Code → Download ZIP**.
3. Распакуйте ZIP. Получится папка `sitebuilder-ccr-6156c21e-10j8dk`.

## 3. Открыть терминал в этой папке
- Windows: откройте папку в Проводнике → в адресной строке напишите `powershell` → Enter.
- macOS: Терминал → `cd ` и перетащите папку в окно → Enter.

## 4. Установить библиотеки (один раз)
Windows:
```
python -m pip install -r requirements-lite.txt
```
macOS:
```
python3 -m pip install -r requirements-lite.txt
```

## 5. Создать администратора (придумайте пароль)
Windows:
```
python -m arturokai.admin create-admin admin
```
macOS:
```
python3 -m arturokai.admin create-admin admin
```
Введите пароль (на экране он не отображается — это нормально), нажмите Enter.

## 6. Запустить сайт
Windows:
```
python -m arturokai.server
```
macOS:
```
python3 -m arturokai.server
```
Оставьте это окно открытым (пока оно открыто — сайт работает).

## 7. Открыть и проверить
В браузере откройте **http://127.0.0.1:7860**
- Раздел **«Админ»** → войдите логином `admin` и своим паролем.
- «Создание кодов» → **Подписка** → тариф → «Создать» → получите коды.
- Проверьте регистрацию обычного пользователя и активацию кода в «Кабинете».

Остановить сайт — закрыть окно терминала (или Ctrl+C).
Все данные (аккаунты, коды) — в папке `data`.
