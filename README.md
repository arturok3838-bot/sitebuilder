# ARTurokAI

Личная нейросеть, которая работает **на вашем компьютере**: без облака, без подписок,
без интернета после первой загрузки моделей.

| Возможность | Модель (меняется в `config.yaml`) |
|---|---|
| 🖼 Фото по описанию и по примеру фото | FLUX.1-schnell (или SDXL) |
| 🎬 Видео до **2 минут** (по тексту или от стартового кадра) | Wan 2.2 TI2V-5B |
| 💻 Написание кода, чат | Qwen2.5-Coder через Ollama |
| 📦 Загрузка ZIP-архивов проекта и выгрузка кода в ZIP | — |

Всё это — в виде **сайта**, который открывается в браузере на компьютере или
телефоне: главная страница, разделы «Фото», «Видео», «Код» и «Галерея» всех работ.

## Как получаются 2 минуты видео
Видеомодели генерируют ~5 секунд за проход. ARTurokAI делает ролик сегментами:
последний кадр каждого сегмента становится стартовым для следующего, так сцена
продолжается непрерывно. 120 секунд ≈ 24 сегмента. Кадры пишутся в файл потоково,
поэтому память не переполняется.

## Требования
- Видеокарта NVIDIA: **от 12 ГБ VRAM** для фото, **от 16–24 ГБ** для видео
  (с `cpu_offload: true` работает и на меньших, но медленнее).
- 32 ГБ ОЗУ, ~60 ГБ места на диске под модели.
- Python 3.10+, [Ollama](https://ollama.com) для кода.

Ориентир по времени на RTX 4090: фото — секунды, 5 сек видео — несколько минут,
2 минуты видео — около часа и больше.

## Установка и запуск
```bash
git clone https://github.com/arturok3838-bot/ARTurokAI.git
cd ARTurokAI

# модели для кода (один раз): быстрая и точная
ollama pull qwen2.5-coder:7b
ollama pull qwen2.5-coder:14b

# Linux / macOS
./run.sh
# Windows
run.bat
```
Откройте сайт: http://127.0.0.1:7860. При первой генерации фото/видео модели
скачаются с Hugging Face (для FLUX может понадобиться `huggingface-cli login`
и принятие лицензии на странице модели). После этого всё работает офлайн.

Чтобы открыть сайт с телефона в той же Wi-Fi-сети: `./run.sh --host 0.0.0.0`,
затем на телефоне зайдите на `http://<IP-компьютера>:7860`.

Генерации ставятся в очередь (видеокарта одна): можно запустить несколько задач
подряд, счётчик ⏳ в шапке показывает, сколько ещё в работе.

## Аккаунты, тарифы и продажа кодов
Доступ к генерации — через аккаунт. После регистрации сразу подключается
**бесплатный тариф** (бесплатные нейросети FLUX.1-schnell и Qwen2.5-Coder 7B,
30 кредитов в день). Платные тарифы и пакеты генераций включаются **кодами**,
которые вы продаёте сами.

| Тариф | Что даёт (по умолчанию) |
|---|---|
| Бесплатный | фото до 768 px, код в быстром режиме, 30 кредитов/день |
| Старт | фото до 1536 px, видео до 30 сек, ZIP, 600 кредитов на 30 дней |
| Про | фото до 2048 px, видео до 2 минут, приоритет в очереди, 2500 кредитов |

Каждое действие стоит кредиты: фото — 2, секунда видео — 3, сообщение в
«Код» — 1. Если генерация не удалась, кредиты возвращаются. В **личном кабинете**
видно, сколько процентов кредитов тарифа осталось, срок подписки и историю.
Цены, лимиты и тарифы меняются в `config.yaml` (раздел `billing`), там же
`seller_contact` — где покупать коды (например, ваш Telegram).

**Два вида кодов** (вид `ARTK-XXXX-XXXX-XXXX`):
- *Подписка* — включает тариф на N дней. Повторный код того же тарифа продлевает его.
- *Пакет генераций* — добавляет кредиты, которые не сгорают.

**Как начать продавать:**
```bash
# 1. Создайте администратора (один раз)
python -m arturokai.admin create-admin artur
# 2. Запустите сайт, войдите этим логином — появится раздел «Админ»:
#    там создаются коды, видно, кто их активировал, и скачивается CSV свободных кодов.
# Или из терминала:
python -m arturokai.admin codes --plan start --count 10 --note "Авито"
python -m arturokai.admin codes --credits 200 --count 5
python -m arturokai.admin list-codes
```
Данные (аккаунты, коды) хранятся в `data/arturokai.db` — делайте копию этого файла.

**Лицензии моделей для продажи.** Модели по умолчанию разрешают коммерческое
использование: FLUX.1-schnell, Wan 2.2, Qwen2.5-Coder 7B/14B — Apache-2.0.
**Нельзя продавать** доступ к FLUX.1-dev, SDXL-Turbo и Qwen2.5-Coder 3B
(у них некоммерческие лицензии) — не ставьте их в `config.yaml`.

**Чтобы покупатели заходили из интернета**, сайт должен быть доступен снаружи:
например, через Cloudflare Tunnel (`cloudflared tunnel --url http://localhost:7860`)
— он сразу даёт HTTPS. Не открывайте сайт в интернет без HTTPS: пароли
передавались бы открытым текстом.

## Уровни усилий
В разделе «Код» три уровня, они по-разному тратят кредиты:
- **⚡ Быстро** — лёгкая модель, короткий ответ, 1 кредит.
- **⚖️ Обычно** — лёгкая модель, развёрнутый ответ, 2 кредита.
- **🎯 Максимум** — большая модель, самый тщательный ответ, 4 кредита (платные тарифы).

Галочка **«Подробное объяснение»** просит модель разложить решение по шагам.
Названия, длину и цену уровней меняйте в `config.yaml` → `llm.efforts`.

## Голос, объяснения и выдача программ
- **🎤 Голосовой ввод** — кнопка микрофона в разделе «Код» (распознавание речи
  в браузере; нужен HTTPS и разрешение на микрофон).
- **Объяснение** — галочка «Подробное объяснение».
- **Выдача программ артефактами** — у каждого блока кода кнопка ⬇ скачивает
  этот файл отдельно, а «Скачать всё кодом (ZIP)» — весь проект из ответов.

## Установка как приложение (ПК, Android, iPhone)
Сайт — это PWA (приложение-сайт), его можно установить как программу:
- **ПК (Chrome/Edge):** кнопка «⤓ Установить» в шапке или значок установки в адресной строке.
- **Android (Chrome):** меню браузера → «Установить приложение» (или та же кнопка).
- **iPhone (Safari):** «Поделиться» → «На экран Домой».

После установки открывается в отдельном окне, с иконкой, и оболочка работает
офлайн. Это кроссплатформенно и не требует публикации в сторах. Если нужны
именно нативные **APK** и **IPA** для магазинов, PWA оборачивают в приложение
(например, Bubblewrap/TWA для Android, обёртка WKWebView для iOS) — это
отдельный шаг со своей подписью; скажите, если он нужен.

## Telegram-бот для выдачи ключей
`arturokai/telegram_bot.py` — бот, через который вы продаёте коды и логины.
Токен и список админов берутся **из переменных окружения, в коде их нет**:
```bash
export ARTUROKAI_BOT_TOKEN=токен_от_@BotFather
export ARTUROKAI_ADMINS=ваш_telegram_id      # узнать: напишите боту /id
export ARTUROKAI_SITE=https://ваш-сайт
python -m arturokai.telegram_bot
```
Покупатель пишет `/start` и получает инструкцию. Админ командами `/plan start 10`,
`/credits 200 5`, `/codes`, `/stats` выпускает и смотрит коды. Внешний адрес боту
не нужен (работает через long polling).

## Защита от взлома, спама и DDoS/DoS
Встроено (`config.yaml` → `security`):
- **лимит запросов** с одного IP в минуту (сверх — ответ 429);
- **ограничение размера** запроса (защита памяти);
- **антифлуд очереди** — не больше N задач генерации на пользователя;
- **защита входа** — блок перебора пароля (10 попыток за 10 минут);
- **заголовки безопасности** (CSP, запрет вставки в чужой сайт, nosniff).

Это первый рубеж. **Крупные DDoS** отражает слой перед сайтом — поставьте его за
**Cloudflare** (бесплатный план уже даёт защиту и HTTPS) или обратный прокси
(nginx) с лимитами. За прокси включите `security.trust_proxy_header: true`,
чтобы лимиты считались по реальному IP.

## Приватность данных пользователей
- Пароли хранятся только в виде **хеша scrypt** (восстановить нельзя).
- Логины, пароли, запросы и работы лежат в базе `data/arturokai.db`, а она в
  `.gitignore` — **в код и в GitHub не попадает**.
- В коде **нет** паролей, токенов и ключей: пароль админа задаётся при создании,
  токен бота — через переменную окружения.
- Каждый пользователь видит только свои файлы и задачи; чужие — 404.

## Публикация сайта (чтобы пользовались из интернета)
Я не могу залить сайт на ваш хостинг из этой среды, но всё для запуска готово.
Самый простой способ с HTTPS — Cloudflare Tunnel:
```bash
./run.sh --host 127.0.0.1            # сайт локально
cloudflared tunnel --url http://localhost:7860   # даёт публичный https-адрес
```
Этот адрес вставьте в `ARTUROKAI_SITE` для бота. Для постоянной работы оформите
именованный туннель Cloudflare на ваш домен (бесплатно). **Без HTTPS публиковать
нельзя** — пароли и голосовой ввод требуют защищённого соединения.

## Скорость ответов
- **⚡ Быстро / 🎯 Точно** — переключатель в разделе «Код». Быстрый режим
  отвечает лёгкой моделью (7b), точный — большой (14b) для сложных задач.
- Модель держится в памяти 60 минут после ответа и загружается заранее —
  при запуске сайта и при открытии раздела «Код», поэтому ответ начинается сразу.
- Ответы короткие и понятные: сразу по делу, по шагам, код целиком.
- Без ZIP используется короткий контекст (быстрее), с ZIP — длинный.
- Под каждым ответом видно скорость: токены в секунду и через сколько
  появились первые слова.
- Фото и видео: если видеопамяти хватает, модель целиком на видеокарте
  (`cpu_offload: auto`), плюс ускорение TF32 на картах NVIDIA RTX.

Всё настраивается в `config.yaml` (раздел `llm`).

## Работа с ZIP и кодом
1. В разделе «Код» перетащите архив проекта — он безопасно распакуется,
   а текст файлов будет передан модели как контекст.
2. Попросите: «найди ошибку», «добавь функцию…», «напиши сайт…».
3. Нажмите «Скачать код из ответов как ZIP» — все блоки кода соберутся в архив
   по путям, которые указала модель.

## Структура
```
arturokai/
  server.py     сервер сайта и API (FastAPI), очередь задач
  store.py      аккаунты, тарифы, кредиты, коды (SQLite)
  admin.py      управление из терминала: администратор, коды
  security.py   лимит запросов, заголовки безопасности (DoS/DDoS)
  telegram_bot.py  Telegram-бот для выдачи кодов и логинов
  image_gen.py  генерация фото
  video_gen.py  генерация видео сегментами
  llm.py        локальная модель для кода (Ollama)
  zip_tools.py  распаковка/упаковка ZIP
web/            сам сайт: index.html, style.css, app.js
config.yaml     все настройки и выбор моделей
tests/          тесты (pip install pytest && pytest)
```
