# ARTurokAI

Личная нейросеть, которая работает **на вашем компьютере**: без облака, без подписок,
без интернета после первой загрузки моделей.

| Возможность | Модель (меняется в `config.yaml`) |
|---|---|
| 🖼 Фото по описанию | FLUX.1-schnell (или SDXL) |
| 🎬 Видео до **2 минут** (по тексту или от стартового кадра) | Wan 2.2 TI2V-5B |
| 💻 Написание кода, чат | Qwen2.5-Coder через Ollama |
| 📦 Загрузка ZIP-архивов проекта и выгрузка кода в ZIP | — |

Всё это — в виде **сайта**, который открывается в браузере на компьютере или
телефоне: главная страница, разделы «Фото», «Видео», «Код» и «Галерея» всех работ.

## Как получаются 2 минуты видео
Видеомодели генерируют ~5 секунд за проход. ARTurokAI делает ролик сегментами:
последний кадр каждого сегмента становится стартовым для следующего, так сцена
продолжается непрерывно. 120 секунд ≈ 24 сегмента. Кадры пишутся в файл потоково,
поэтому память не переполняется.

## Требования
- Видеокарта NVIDIA: **от 12 ГБ VRAM** для фото, **от 16–24 ГБ** для видео
  (с `cpu_offload: true` работает и на меньших, но медленнее).
- 32 ГБ ОЗУ, ~60 ГБ места на диске под модели.
- Python 3.10+, [Ollama](https://ollama.com) для кода.

Ориентир по времени на RTX 4090: фото — секунды, 5 сек видео — несколько минут,
2 минуты видео — около часа и больше.

## Установка и запуск
```bash
git clone https://github.com/arturok3838-bot/ARTurokAI.git
cd ARTurokAI

# модель для кода (один раз)
ollama pull qwen2.5-coder:14b

# Linux / macOS
./run.sh
# Windows
run.bat
```
Откройте сайт: http://127.0.0.1:7860. При первой генерации фото/видео модели
скачаются с Hugging Face (для FLUX может понадобиться `huggingface-cli login`
и принятие лицензии на странице модели). После этого всё работает офлайн.

Чтобы открыть сайт с телефона в той же Wi-Fi-сети: `./run.sh --host 0.0.0.0`,
затем на телефоне зайдите на `http://<IP-компьютера>:7860`.

Генерации ставятся в очередь (видеокарта одна): можно запустить несколько задач
подряд, счётчик ⏳ в шапке показывает, сколько ещё в работе.

## Работа с ZIP и кодом
1. В разделе «Код» перетащите архив проекта — он безопасно распакуется,
   а текст файлов будет передан модели как контекст.
2. Попросите: «найди ошибку», «добавь функцию…», «напиши сайт…».
3. Нажмите «Скачать код из ответов как ZIP» — все блоки кода соберутся в архив
   по путям, которые указала модель.

## Структура
```
arturokai/
  server.py     сервер сайта и API (FastAPI), очередь задач
  image_gen.py  генерация фото
  video_gen.py  генерация видео сегментами
  llm.py        локальная модель для кода (Ollama)
  zip_tools.py  распаковка/упаковка ZIP
web/            сам сайт: index.html, style.css, app.js
config.yaml     все настройки и выбор моделей
tests/          тесты (pip install pytest && pytest)
```
